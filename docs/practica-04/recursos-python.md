Recursos de Python

Recurso 1. Documentación oficial de Python

Nombre del recurso: Documentación oficial de Python.

URL: https://docs.python.org/es/3/

Tema que aborda: Información general del lenguaje Python, sus funciones, bibliotecas, sintaxis y configuración.

Tipo de información que ofrece: Documentación técnica, explicaciones, referencias y guías de consulta.

Utilidad para el proyecto integrador: Permite consultar cómo funciona Python y conocer las instrucciones necesarias para desarrollar y mejorar programas relacionados con la automatización de redes.

Ejemplo de una situación en la que lo consultaría: Lo consultaría si necesito conocer la forma correcta de utilizar una función de Python o resolver una duda sobre el código de dispositivos.py.


Recurso 2. Tutorial oficial de Python

Nombre del recurso: Tutorial oficial de Python.

URL: https://docs.python.org/es/3/tutorial/

Tema que aborda: Aprendizaje de Python, estructuras de datos, control de flujo, funciones, módulos y manejo de errores.

Tipo de información que ofrece: Explicaciones paso a paso, ejemplos de código y capítulos organizados por temas.

Utilidad para el proyecto integrador: Ayuda a comprender y mejorar el programa dispositivos.py, especialmente para almacenar información, recorrer listas y buscar dispositivos de red por su nombre.

Ejemplo de una situación en la que lo consultaría: Lo consultaría si necesito crear una función que busque un dispositivo por su nombre y muestre su información, como su nombre o dirección IP.
