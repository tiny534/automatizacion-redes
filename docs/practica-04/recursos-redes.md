# Recursos de redes y automatización

## Recurso 1. GNS3

- **Nombre del recurso:** GNS3.
- **URL:** https://www.gns3.com/
- **Tema que aborda:** Simulación y diseño de redes de computadoras.
- **Tipo de información que ofrece:** Información sobre el programa, sus funciones, descargas y recursos para crear topologías de red.
- **Utilidad para el proyecto integrador:** Permite practicar configuraciones y comprender cómo se conectan los dispositivos de una red.
- **Ejemplo de una situación en la que lo consultaría:** Lo consultaría para aprender a crear una topología con routers y switches y comprobar la comunicación entre dispositivos.

## Recurso 2. Biblioteca estándar de Python

- **Nombre del recurso:** Biblioteca estándar de Python.
- **URL:** https://docs.python.org/es/3/library/
- **Tema que aborda:** Módulos y herramientas incluidas con Python.
- **Tipo de información que ofrece:** Documentación técnica, explicaciones de módulos y ejemplos de sus funciones.
- **Utilidad para el proyecto integrador:** Ayuda a identificar herramientas que pueden utilizarse para procesar información, administrar archivos y automatizar tareas mediante Python.
- **Ejemplo de una situación en la que lo consultaría:** Lo consultaría para revisar cómo utilizar un módulo que permita leer un archivo con información de dispositivos de red.

## Recurso 3. Netmiko

- **Nombre del recurso:** Netmiko.
- **URL:** https://github.com/ktbyers/netmiko
- **Tema que aborda:** Automatización de conexiones SSH a dispositivos de red mediante Python.
- **Tipo de información que ofrece:** Código fuente, instrucciones de instalación, documentación y ejemplos de uso.
- **Utilidad para el proyecto integrador:** Puede servir como referencia para una futura ampliación del proyecto que permita conectarse a equipos de red y automatizar tareas de configuración.
- **Ejemplo de una situación en la que lo consultaría:** Lo consultaría para investigar cómo establecer una conexión SSH con un dispositivo compatible y ejecutar comandos de administración de red.
