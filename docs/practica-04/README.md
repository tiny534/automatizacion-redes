### Preguntas sobre colaboración técnica

**1. ¿Qué ventajas tiene consultar una comunidad de colaboración en lugar de buscar información sin un objetivo definido?**

Permite encontrar experiencias y soluciones relacionadas con el problema específico. Además, se pueden revisar explicaciones, comparar respuestas y aprovechar los conocimientos de otras personas.

**2. ¿Por qué es importante revisar si una pregunta ya fue respondida antes de publicar una nueva?**

Porque puede existir una solución que ya resuelva el problema. Revisar las respuestas anteriores ahorra tiempo, evita preguntas repetidas y permite aprender de experiencias similares.

**3. ¿Qué información debe incluir una pregunta técnica para que otras personas puedan ayudar?**

Debe describir el problema, indicar el programa y la versión utilizada cuando sea relevante, incluir el código relacionado y mostrar el mensaje de error completo. También es útil explicar qué resultado se esperaba obtener.

**4. ¿Por qué es importante describir los pasos que se intentaron y los errores que aparecieron?**

Porque ayuda a comprender qué se hizo, facilita identificar la posible causa del problema y evita que otras personas recomienden nuevamente soluciones que ya se intentaron sin éxito.

**5. ¿Qué comportamiento debe tener un estudiante al solicitar ayuda o utilizar una solución publicada?**

Debe ser respetuoso, explicar el problema con claridad, agradecer la ayuda y reconocer las fuentes consultadas. También debe comprender la solución, verificar que funcione y adaptarla a su proyecto en lugar de copiarla sin revisarla.

## 7. Estrategia para resolver un problema técnico

Se planteó un problema en el archivo `dispositivos.py`: el programa muestra los dispositivos R1 y R2, pero no logra encontrar un dispositivo cuando se busca por su nombre. Para analizar esta situación, se propone revisar el código, verificar los nombres registrados y comprobar que la búsqueda esté implementada correctamente.

| Paso | Acción para resolver el problema |
|---|---|
| 1. Identificar el problema | Ejecutar el programa y comprobar que los dispositivos R1 y R2 se muestran, pero la búsqueda por nombre no funciona. |
| 2. Revisar el código | Analizar cómo se almacenan los dispositivos y cómo se realiza la búsqueda por nombre. |
| 3. Consultar documentación | Revisar la documentación oficial de Python para verificar el uso correcto de listas, diccionarios, cadenas de texto y condiciones. |
| 4. Buscar información | Consultar Stack Overflow en español o GitHub para investigar casos similares y posibles soluciones. |
| 5. Probar una solución | Corregir la búsqueda y ejecutar el programa con nombres existentes y nombres que no estén registrados. |
| 6. Verificar resultados | Confirmar que R1 y R2 se encuentren correctamente y que el programa responda cuando el dispositivo no existe. |
