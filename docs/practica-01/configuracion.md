# Configuración del entorno

## Estructura del proyecto

El proyecto se organizó con las siguientes carpetas y archivos:

- `src/`: contiene el código fuente del programa.
- `tests/`: destinada a las pruebas.
- `data/`: destinada a los datos.
- `docs/practica-01/evidencias/`: almacena las capturas de pantalla.
- `.venv/`: contiene el entorno virtual de Python.
- `.vscode/`: contiene la configuración de Visual Studio Code.

## Entorno virtual

Se creó el entorno virtual con:

```powershell
python -m venv .venv
```

Se activó con:

```powershell
.\.venv\Scripts\Activate.ps1
```
