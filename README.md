# automatizacion-redes

Proyecto de prácticas de automatización de redes utilizando Python y GNS3.

## Práctica 1. Preparación del entorno
Se preparó el entorno de trabajo para desarrollar programas de automatización de redes.

## Práctica 2. Simulación de redes con GNS3
Se trabajó con GNS3 para crear y configurar una topología de red simulada.

## Práctica 3. Programa de Python para representar dispositivos de red

Se desarrolló un programa en Python para representar y consultar información de dispositivos de red.

### Funciones implementadas
- Inventario de dispositivos mediante listas y diccionarios.
- Registro de routers y switches.
- Información de dirección IP, interfaz, estado y fabricante.
- Uso de ciclos `for` y condiciones `if`.
- Función para mostrar información de cada dispositivo.
- Búsqueda de dispositivos por nombre.

### Archivos de la práctica
- Código: `src/dispositivos.py`
- Documentación: `docs/practica-03/README.md`
- Evidencias: `docs/practica-03/evidencias/`
